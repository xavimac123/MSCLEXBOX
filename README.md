# MSC-LEXBOX

Consulta normativa ecuatoriana por materia — Macías Sánchez Consultores.

App web instalable (PWA): Constitución, Código Civil, COGEP, COFJ, LOPDP y su Reglamento, más resoluciones, guías y casos sancionatorios de la SPDP. Funciona sin conexión después de la primera visita.

**Abrir / instalar:** https://xavimac123.github.io/MSCLEXBOX/

Para actualizar: reemplazar `index.html` (y la carpeta `img/` si cambia) y subir la versión del caché en `sw.js`.
