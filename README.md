# MSC-LEXBOX

Consulta normativa ecuatoriana por materia — Macías Sánchez Consultores.

App web instalable (PWA): Constitución, LOGJCC, Código Civil, CONA, COGEP, COFJ, LAM, Código del Trabajo, Código de Comercio, Reglamento LCE, COA, LOPDP y su Reglamento, LOTTTSV y su Reglamento; resoluciones, guías y casos de la SPDP; resoluciones judiciales (CJ y FGE) sobre ocultamiento de datos; sentencias de la Corte Constitucional; glosario jurídico y función de cita (APA, MLA, Chicago). Funciona sin conexión después de la primera visita.

**Abrir / instalar:** https://xavimac123.github.io/MSCLEXBOX/

Para actualizar: reemplazar `index.html` (y la carpeta `img/` si cambia) y subir la versión del caché en `sw.js`.
